# JustNatur Shopify Theme

Editorial wellness theme for **JustNatur**, inspired by the Himalibuti product-page pattern: clean storytelling, pack/combo selection, trust rows, ritual sections, and sticky add-to-cart.

## Install

1. Zip the theme folder (this repository root) or push to a connected Shopify theme repo.
2. In Shopify Admin → **Online Store → Themes → Add theme → Upload zip**.
3. Publish or preview the theme.
4. Assign menus named `main-menu` and `footer` (or update header/footer settings).

## What’s included

- **Homepage** — full-bleed brand hero, trust marquee, promise, story, featured products, benefits, newsletter
- **Product page (CVR funnel)** — gallery, pack picker, urgency bar, problem/causes, before/after reviews, brand comparison, ingredients, timeline, how-to-use, guarantee, FAQ, reviews, final CTA
- **Collection, cart, search, 404, pages, collections list**
- **Cart drawer** with AJAX add-to-cart
- Theme editor settings for colors, logo, and section content

## Design notes

- Brand-first hero (`Just` + italic `Natur`)
- Display type: Fraunces · Body: Plus Jakarta Sans
- Palette: botanical green accent on warm off-white, ink ritual sections
- Motion: scroll reveals, marquee, sticky ATC entrance

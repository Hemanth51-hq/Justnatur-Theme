# JustNatur Shopify Theme

Mobile-first CRO theme for **JustNatur** (Kesha Mula), inspired by Himalibuti-style product storytelling with JustNatur brand tokens.

## Brand system
- Primary `#B53325` · Accent `#E5A657` · Secondary `#DFBC94` · Background `#F4E2CE`
- Typography: Poppins 400–700
- Custom SVG icon library (no emoji)

## CRO features
- Rotating announcement bar
- Transparent → blur sticky header + mobile drawer
- Frido-style buy box: packs, COD, delivery, returns, payment chips, offer progress, optional scarcity, recently purchased
- Sticky mobile ATC
- Before/after reviews, comparison, ingredients, timeline, how-to, FAQ, guarantee
- Video carousel (YouTube / MP4 / Shopify video)
- Frequently Bought Together
- Founder story + Instagram grid
- Cart progress rewards (Free Shipping → Free Hair Oil → Premium Gift)
- WhatsApp FAB
- Subtle GSAP motion (≤600ms)

## Install
Upload theme zip / connect repo → assign `main-menu` & `footer` → set complement product on FBT → upload before/after & Instagram images → enable scarcity only with real stock copy.

# JustNatur Theme

Premium mobile-first Shopify theme for JustNatur — warm modern Ayurveda with founder-led trust and conversion-focused product storytelling.

## Art direction
- Cream canvas `#F4E2CE`, primary `#B53325`, gold `#E5A657`, sand `#DFBC94`
- Poppins editorial type scale
- Large whitespace, soft depth, minimal chrome
- Chapter-based homepage rhythm
- Founder letter as trust centerpiece

## CRO system
Honest packs · COD/delivery/returns · payment chips · offer progress · sticky ATC · before/after proof · video rail · FBT · FAQ · rotating announcements

## Files of note
- `assets/premium.css` — art direction layer
- `assets/base.css` — structural system
- `assets/theme.js` — interactions + GSAP
